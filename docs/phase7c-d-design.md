# Phase 7-C-D Response Area Generalization

## Failure pattern

Response layouts were discoverable in the pipeline, but diagnostics did not expose a shared classification for answer lines, choices, tables, diagrams, working areas, and ordinary text responses. Visual crop storage also contained a fixed syllabus path.

## Design

- Classify response layout from generic textual and geometry signals.
- Preserve explicit answer-line geometry as the strongest signal.
- Generate visual crop keys from stable paper identity.
- Keep inferred areas low-confidence and retain their source explanation.

## Protection

Required leaf coverage and response-area validation remain mandatory.
