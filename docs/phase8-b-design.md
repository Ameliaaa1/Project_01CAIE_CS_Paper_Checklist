# Phase 8-B Regression Intelligence

## Design

Maintain golden, edge-case, cross-syllabus, and future-syllabus fixtures. Each result records fixture class, syllabus, source file, expected structural counts, actual counts, and a failure domain.

Regression failures use shared domains such as source, document structure, question structure, mark allocation, response area, text quality, traceability, and governance.

## Guardrails

Stable IDs, question/leaf counts, marks, and existing validation gates remain unchanged.
