# PR-010C.3A-2A-0 Single-PDF Ownership Runtime Integration Project Plan

## 1. 文档目的

本项目文档用于定义并实施：

```text
PR-010C.3A-2A-0
Single-PDF Ownership Runtime Integration
```

当前已经完成：

- Canonical Ownership Model 基础模块；
- stable Source Span ID；
- geometry-first Visual Line；
- context-aware Roman anchor classifier；
- Ownership Assignment DTO；
- classification 与 owner registry；
- `Index Register (IX)` fixture。

但 ownership model 尚未被 `scripts/pr010c-canonical-boundary-root-fix.js` 导入和调用，因此真实 dry-run 仍然绕过该模型。

本阶段只完成一个最小闭环：

```text
一份真实 PDF
→ PDF geometry
→ buildOwnershipModel()
→ ownership evidence
→ smoke report
```

本阶段不处理 216 份 PDF，不执行 Canonical Boundary Contract，不修改 candidate，也不写入 Production。

## 3. 本阶段目标

只针对：

```text
9618-2024-ON-12-QP
```

完成以下验证：

1. root-fix dry-run 成功 import `buildOwnershipModel`；
2. `buildOwnershipModel()` 在真实 PDF geometry 上执行；
3. `sourceSpanCount > 0`；
4. `visualLineCount > 0`；
5. `anchorCount > 0`；
6. `ownershipAssignmentCount > 0`；
7. `Index Register (IX)` 被分类为 `NON_STRUCTURAL_TOKEN`；
8. `(IX)` 不会创建伪 child；
9. 至少一个合法 `(i)`、`(ii)` 或 `(iii)` 被分类为 `ROMAN_CHILD`；
10. `productionWrite=false`；
11. candidate text 和 Stable IDs 不变。

## 7. Runtime 调用

在 geometry extraction 后执行：

```js
const geometry = await extractPdfGeometry(paper.sourceFile);

const ownershipModel = buildOwnershipModel({
  geometry,
  paperId: paper.id
});

const fresh = sliceQuestionPaper(geometry, {
  // 保持原有参数
});
```

如果 `paper.id` 不是实际 QP ID，应使用项目中稳定的：

```text
paperId
paperGroupId
sourceFile-derived ID
```

不得使用随机或临时 ID。

---

## 8. Ownership Model 输出检查

`buildOwnershipModel()` 必须返回：

```text
sourceSpans
visualLines
anchors
ownershipAssignments
registries
```

每个字段必须是可序列化的 plain JSON 数据。

不允许返回：

```text
function
circular reference
BigInt
runtime-only class instance
unresolved Map/Set
```

如果内部使用 Map/Set，必须通过明确 DTO 转换输出。

```json

  "paperId": "9618-2024-ON-12-QP",
  "page": 1,
```

## 19. Hard Acceptance Criteria

PR-010C.3A-2A-0 通过必须同时满足：

1. root-fix 成功 import `buildOwnershipModel`；
2. `buildOwnershipModel()` 在真实 PDF geometry 上执行；
3. 只处理 `9618-2024-ON-12-QP`；
4. `selectedPaperCount = 1`；
5. `sourceSpanCount > 0`；
6. `visualLineCount > 0`；
7. `anchorCount > 0`；
8. `ownershipAssignmentCount > 0`；
9. Source Span 使用稳定 ID；
10. Source Span 保留真实 bbox 或显式 missing；
11. Visual Line 使用 geometry-first order；
12. `Index Register (IX)` 被识别为 `NON_STRUCTURAL_TOKEN`；
13. `(IX)` 不创建伪 child；
14. 至少一个合法 Roman child 被识别为 `ROMAN_CHILD`；
15. ownership artifacts 成功写出；
16. artifact SHA-256 完整；
17. candidate text 不变；
18. Stable IDs 不变；
19. Production write 为 false；
20. 未修改 `sourceTraceForLayoutLine()`；
21. 未将 ownership 写回 candidate schema；
22. 未执行 216 PDF full corpus；
23. 未使用 semantic diff 构造 ownership；
24. 未由 report serializer 创建 assignments。

---

## 20. Failure Conditions

以下任一情况发生，本阶段必须为 `BLOCKED`：

```text
ownership model 未 import
ownership model 未执行
selectedPaperCount != 1
sourceSpanCount = 0
visualLineCount = 0
anchorCount = 0
ownershipAssignmentCount = 0

candidate text 变化
Stable IDs 变化
Production write = true
运行范围扩大到 216 PDF
ownership 从 semantic diff 或 report 层构造
```
